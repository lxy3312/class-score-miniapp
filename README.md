# 班级积分站

原生微信小程序源码与面向首次接手者的部署教程。支持学生名单、班级/小组积分榜、积分记录、统计和管理员设置。

## 在自己的小程序账号上用

教程依次说明：准备自己的 AppID → 解压并替换原配置 → 导入开发者工具 → 创建自己的云环境 → 初始化集合、班级和学期 → 部署 `whoami` / `score` → 配置自己的管理员 openid → 真实记分验收 → 上传体验版 → 审核发布。

开发者工具导入的是 `class-score-miniapp/`，该层直接含 `app.json`。主项目无需 npm 构建；两个云函数分别选择“云端安装依赖”。

**本包保留原项目连接配置。首次运行前按教程第 03 节换成自己的 AppID，并先将 `app.js` 两项设为 `YOUR_` 占位；创建自己的环境和班级后填入实际值。只改班级名称不会独立部署。**

仓库未带云端数据库备份、原班真实名单附件、账号权限、私有电脑配置或内部验证日志。`preview.html` 是离线外观预览，不能代替真实云端小程序。

## 验证范围

发布包结构与 ZIP 完整性已检查，本地统计自检通过。原优化版此前已实测启动、云读取、管理员身份及无效输入拒绝。目标账号的成功记分、编辑、撤销、普通浏览者、跨设备同步和正式发布，需要按验收清单实际验证。

页面新增评分规则默认归入 `study`；体育、劳动和纪律分类设置方式见教程。当前未实现按家长/学生只查看本人数据的隔离；首字显示只影响展示。

维护者如已安装 Node.js，可执行：

```text
cd class-score-miniapp
node tests/score.js
```
