# Logo 使用说明

这套 Logo 与小程序的蓝紫渐变视觉保持一致：

- 打开的书本：代表班级学习与共同成长。
- 青绿色上升轨迹：代表积分变化、进步和实时反馈。
- 金色星芒：代表阶段性表现与荣誉。

## 文件

- `logo-mark.svg` / `logo-mark.png`：方形主标识，适合首页、头像、启动图和小尺寸图标。PNG 为 192 × 192，保留透明背景。
- `logo-lockup.svg` / `logo-lockup.png`：横版组合标识源文件，适合设置页、分享海报和班级公告。PNG 为 640 × 181，保留透明背景。
- `logo.png`：完整横版 PNG，内容与 `logo-lockup.png` 相同，作为直接使用的主文件。
- `logo-square.png`：完整方形 PNG，内容与 `logo-mark.png` 相同，作为直接使用的方形文件。

优先使用 SVG；微信小程序页面已使用 PNG 兼容版，避免部分基础库对 SVG 的支持差异。使用时请保留 Logo 周围的留白，不要拉伸、旋转或重新着色。
