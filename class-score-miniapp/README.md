# 班级积分站

本目录是微信开发者工具的导入目录（这一层直接包含 app.json）。
首次独立部署请先打开上一级目录的“朋友独立发布教程.html”。

本包应用源码与已检查的优化版一致，仍带原项目连接配置。
先按教程第 03 节换为自己的 AppID，并将 app.js 两项设为 YOUR_ 占位，
再导入、开通自己的云环境、建立班级和学期，填入自己的真实值。
不要继续连接原班级，也不要沿用原 openid。

主项目无需 npm 构建。whoami 与 score 通过云端安装依赖分别部署。
本包不含原班真实名单、云数据库备份或账号权限。
上一级 templates/ 提供可编辑配置和虚构名单格式示例。

如维护者已安装 Node.js，可在本目录运行本地统计自检：

```text
node tests/score.js
```

本地自检不替代自己账号中的真实云端读写、浏览者身份和发布验收。
